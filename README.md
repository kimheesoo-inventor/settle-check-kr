# 정산 확인기 (settle-check-kr) v0

쿠팡 WING에서 내려받은 **주문 엑셀**과 **정산 엑셀**을 브라우저에 넣으면, 배송완료 후 정한 기간이 지났는데도 **정산 엑셀에 주문번호가 없는 주문**을 골라 보여 주는 무료 도구입니다. 계정 연결이 필요 없고, 파일은 서버로 보내지 않습니다.

쿠팡과 관련 없는 개인 프로젝트이며, AI 도구의 도움을 받아 만들었습니다. 결과는 참고용입니다. 실제 정산 금액과 지급 일정은 반드시 쿠팡 WING에서 확인해 주세요.

## 왜 만들었나

판매가 늘면 "배송은 끝났는데 정산 내역에서 안 보이는 주문"을 엑셀 두 개를 오가며 손으로 찾아야 할 때가 있습니다. 정산 내역을 자동으로 맞춰 주는 유료 서비스나 대행도 있습니다. 이 도구는 그런 서비스를 대신하려는 것이 아니라, 계정을 연결하지 않고 내려받은 파일만으로 먼저 한 번 훑어보고 싶을 때 쓰도록 만든 간단한 무료 도구입니다.

## 쓰는 법

1. WING에서 주문번호와 배송완료일이 들어 있는 주문 목록 엑셀을 내려받습니다(예: 주문/배송 엑셀). 메뉴 이름은 예시이며 실제 화면과 다를 수 있습니다.
2. 주문번호가 들어 있는 정산 관련 엑셀을 내려받습니다(예: 정산현황·매출내역 엑셀). 정산 엑셀은 주문 엑셀 기간의 끝보다 최소 10일(기본 설정: 기다리는 날 7일 + 여유일 3일), 넉넉하게는 2주 뒤까지 포함해 받으세요. 매출 인식 기준이 아니라 입금(지급)일 기준 자료라면 몇 주 더 필요할 수 있습니다.
3. `index.html`을 열고 두 파일을 넣은 뒤, 자동으로 고른 열이 맞는지 확인하고 "비교하기"를 누릅니다.

파일 없이 먼저 보려면 "가상 예시 데이터로 해 보기"를 누르세요. 예시는 이 화면을 보여 주려고 만든 가상 데이터입니다.

## 판정 방법

기준일, 구매확정까지 기다리는 날(기본 7일), 여유일(기본 3일)을 씁니다. 같은 주문번호의 여러 줄은 한 주문으로 묶습니다.

| 분류 | 조건 |
| --- | --- |
| 확인 필요 | 배송완료일 + 기다리는 날 + 여유일 < 기준일, 정산 엑셀에 주문번호 없음, 상태가 취소·반품·교환 아님 |
| 기다리는 중 | 배송완료했지만 아직 위 기간 안(정확히 기간 마지막 날 포함) |
| 정산 확인됨 | 정산 엑셀에 주문번호 있음 |
| 제외 | 모든 줄이 취소·반품·교환, 또는 배송완료일 없음(미배송 등)·날짜를 읽지 못함 |
| 정산 엑셀에만 있음 | 정산 엑셀에는 있는데 주문 엑셀에는 없는 주문(다른 기간 주문일 수 있음) |

- "7일이 지나면 구매확정되어 정산 엑셀에 나타난다"는 것은 이 도구의 **가정**입니다. 쿠팡 마켓플레이스 안내(자주 묻는 질문)에는 고객이 구매확정을 누르지 않으면 배송완료일 기준 7일 후 구매확정 처리된다고 되어 있지만, 정책·배송 유형에 따라 다를 수 있습니다. 실제 기준이 다르면 화면에서 숫자를 바꾸세요.
- "확인 필요" 금액 합은 **주문 엑셀 기준 금액의 합**이며, 정산 예정액이 아닙니다.
- 정산 엑셀에 날짜 열(매출인식일·구매확정일·정산일 등)이 있으면 날짜 범위를 보여 주고, 예상 구매확정일이 그 범위 밖인 주문에는 메모를 붙입니다.
- 주문번호는 공백·하이픈을 빼고 비교합니다. `1.23457E+15`처럼 지수 형태이거나 17자리 이상 숫자면 경고합니다(엑셀에서 끝자리가 바뀌었을 수 있음).

## 읽을 수 있는 파일

- `.xlsx`: 외부 라이브러리 없이 브라우저의 압축 풀기 기능(`DecompressionStream`)으로 읽습니다. 첫 시트를 읽고, 시트가 여러 개면 고를 수 있습니다.
- `.csv`: UTF-8을 먼저 시도하고, 아니면 EUC-KR로 다시 읽습니다. 쉼표·탭·세미콜론 구분을 자동으로 알아봅니다.
- `.xls` 이름이지만 실제로는 HTML 표인 파일도 읽습니다.
- 파일 위쪽에 제목줄이나 빈 줄이 있어도 앞 15줄 중 열 제목처럼 보이는 줄을 찾습니다.

## 한계

- 실제 WING 엑셀의 열 이름을 모두 확인하지 못했습니다. 열 제목의 낱말로 자동 선택하고, 사용자가 직접 바꿀 수 있게 했습니다.
- 옛 엑셀(`.xls` 바이너리)과 암호가 걸린 엑셀은 읽지 못합니다. 엑셀에서 `.xlsx` 또는 CSV로 다시 저장해 주세요.
- 주문번호 단위로만 비교하므로 한 주문 안에서 일부 상품만 정산된 경우는 잡지 못합니다. 금액이 맞는지도 비교하지 않습니다.
- 교환 주문은 따로 확인하도록 "제외"로 둡니다.
- 정산 엑셀 기간이 짧으면 실제로 정산된 주문도 "확인 필요"에 나올 수 있습니다.
- 구매확정이 늦어졌거나 정산이 보류(유보)된 주문, 반품·교환을 접수 중인 주문, 주문번호 표기가 서로 다른 주문도 "확인 필요"에 나올 수 있습니다. "확인 필요"는 정산 누락 확정이 아니라 이 정산 엑셀에서 못 찾았다는 뜻입니다.
- 아주 오래된 브라우저(압축 풀기 기능 없음)에서는 `.xlsx`를 읽지 못하니 CSV를 쓰세요.
- 세무·회계 조언이 아닙니다.

## 개인정보

파일은 서버로 보내지 않습니다. 고른 파일은 이 브라우저 안에서만 읽고 처리합니다. 페이지의 외부 스크립트는 방문 수를 세는 Cloudflare Web Analytics(쿠키를 쓰지 않는 방문 통계) 하나뿐이고 글꼴은 없습니다. 페이지 안의 보안 설정(CSP)으로 방문 통계 주소(cloudflareinsights.com) 외의 외부 연결을 막아 두었습니다. 이 통계에는 고른 파일의 내용이 들어가지 않습니다.
